How this works
The active character's LoRA is injected automatically on /imagine. Switch character and the LoRA follows, no settings change needed. In ComfyUI, title a LoraLoader node IMAGINE_LORA. The list is pulled live from ComfyUI.
Workflow
Upload a workflow exported in API format. In ComfyUI: enable Dev Mode (Settings → Enable Dev Mode Options), then Graph → Export (API).

ComfyUI
Start ComfyUI with --listen so it accepts network connections:
python main.py --listen 0.0.0.0 --port 8188 --enable-cors-header
If ComfyUI runs on a different machine than SillyTavern, --enable-cors-header is required — without it the browser blocks cross-origin requests even if the port is reachable.
